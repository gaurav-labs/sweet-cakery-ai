# CN-001

## Title

WooCommerce Connector

---

## Purpose

Communicate with the WooCommerce REST API.

---

## Responsibilities

- Authenticate with WooCommerce.
- Create draft products.
- Publish draft products.
- Update products.
- Delete products.
- Upload product images.
- Return structured responses.

---

## Input

Connector-specific request models.

---

## Output

Connector-specific response models.

---

## Never

- Invoke AI.
- Apply business rules.
- Access workflow memory.
- Make workflow decisions.
- Perform business validation.

---

## Failure

Return a structured error to the calling tool.
