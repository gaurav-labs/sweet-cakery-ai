## Why this project?

Sweet Cakery is a WooCommerce based online cake store.

Many day-to-day tasks are repetitive and time-consuming, such as publishing products, answering customer questions, tracking orders, and managing product information.

The goal of this project is to use AI to automate these workflows while keeping the system secure, maintainable, and production-ready.

---

## Goals

- Reduce manual work.
- Improve the customer experience.
- Learn and apply modern AI engineering in a real production system.
- Build everything with production quality rather than as demos.

---

## Principles

- Business problems first.
- Architecture before code.
- Deterministic code before AI.
- Security by design.
- Keep it simple.
- Build for today, but don't block tomorrow.

---

## Success

The project is successful if Sweet Cakery uses it in production and it saves real time every week.
